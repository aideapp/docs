# Aide docs

The source of [docs.aide.app](https://docs.aide.app), a [Mintlify](https://mintlify.com) site.

## Where the content comes from

The guides are generated from Aide's help-center articles, which live in the Aide monorepo at
`apps/backend/resources/help-center/*.md`. The API reference is generated by Mintlify from
`api-reference/openapi.json`, a copy of the monorepo's `docs/openapi/v1.json`;
`api-reference/production-server.overlay.json` points its playground at the production API.

Don't edit the generated pages (`getting-started/`, `aide-ai-agent/`, `aide-chat/`, `channels/`,
`aide-helpdesk/`, `automation/`, `knowledge/`, `shopify/`, `integrations/`, `copilot/`,
`analytics/`, `billing/`, `developers/`, `account/`) or the collection groups in `docs.json`:
change the article in the monorepo and re-sync. `index.mdx`, the "Overview" group, the API
reference tab, the redirects and the rest of `docs.json` are edited by hand.

## Re-sync from the help center

With a checkout of the Aide monorepo at `<monorepo>` (Node 18 or later, no dependencies):

```
node scripts/sync-help-center.mjs <monorepo>/apps/backend/resources/help-center --openapi <monorepo>/docs/openapi/v1.json
```

The script rewrites only what it generated last time, as listed in
`scripts/help-center-manifest.json`: one page per article at `<collection>/<id>.mdx`, the
navigation groups named after the collections (in help-center order) and the copied OpenAPI file.
Leave out `--openapi` to update only the guides. Articles that quote another article's exact
title, such as see "Connect your Shopify store", get a link to that page.

If an article is renamed or removed, add a redirect from its old path in `docs.json`.

Then check the result and open a PR:

```
npx mint@latest validate
npx mint@latest broken-links --check-redirects
```

## Development

Preview locally with the [Mintlify CLI](https://www.npmjs.com/package/mint), from the root of
this repo:

```
npx mint@latest dev
```

View your local preview at `http://localhost:3000`.

## Publishing changes

Mintlify's GitHub app deploys the default branch to production automatically; pull requests get a
preview deployment.

## Need help?

- If your dev environment isn't running: run `mint update` to ensure you have the most recent version of the CLI.
- If a page loads as a 404: make sure you are running in a folder with a valid `docs.json`.
- [Mintlify documentation](https://mintlify.com/docs)
