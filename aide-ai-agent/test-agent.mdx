The preview lets you talk to the Aide AI Agent exactly as a customer would, without anything reaching a real customer. It works while the agent is still a draft.

## Start a test conversation

Open Aide AI Agent. The preview sits on the right of the page. Type a question the way a customer would. The agent answers with the same knowledge, scenarios, fields and instructions it would use live, including handoffs. Changes you save show up in the next reply.

You can try both a chat and an email: in email mode, write a subject and a body as a customer would.

To start over, reset the preview.

## Pretend to be a specific customer

Set who the preview customer is from the fields above the preview:

- **Customer**: a name, an email and other customer details.
- **Conversation fields**: values for your conversation fields.

This is the same information `Aide('identify')` passes from your website, so you can check how the agent treats logged-in or VIP customers. If you use a real customer's email, the agent can look up their orders.

## Review test conversations

Aide AI Agent > Logs lists every conversation the agent has been in, previews included, so you can reread a test and see what the agent did.

## What a test costs

Preview replies don't count towards your monthly AI replies. They do use your workspace's daily AI usage limit, like any other AI reply.

## Simulator

A simulator that replays past conversations against your agent isn't available yet. Until then, try a handful of typical questions in the preview before each change.
